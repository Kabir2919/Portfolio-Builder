# Portfolio-Builder
This is a basic Portfolio Builder built with React JS. It allows users to input their basic personal and professional details and generates a simple, clean portfolio website based on the information provided.

✨ **Features** ✨
1) User-friendly input form for personal details
2) Auto-generated portfolio layout
3) Built with React for a responsive and smooth experience

🚀 **Getting Started** 🚀 
1. Clone the repository:
"git clone https://github.com/your-username/portfolio-builder.git"
"cd portfolio-builder"
2. Install dependencies:
Make sure you have Node.js and npm installed. Then run:
"npm install"
You also need to manually install:
"npm install react-icons react-router-dom"
3. Run the app
"npm run dev"
The app will start at http://localhost:5173 (or similar, depending on your Vite config).

📁 **Tech Stack** 📁
React JS
Vite
React Router DOM
React Icons
